## 🎨 CUSTOMIZATION OPTIONS

### **Change Overlay Color:**
Edit `app/globals.css` - line `.hero-video-overlay`:

```css
/* Current: Electric Indigo */
rgba(76, 69, 245, 0.3) 50%

/* Purple: */
rgba(139, 92, 246, 0.3) 50%

/* Blue: */
rgba(59, 130, 246, 0.3) 50%

/* Red: */
rgba(239, 68, 68, 0.3) 50%
```

### **Adjust Overlay Darkness:**
```css
/* Lighter (more video visible): */
rgba(17, 24, 39, 0.65) 0%

/* Darker (more contrast): */
rgba(17, 24, 39, 0.95) 0%
```

### **Change Hero Text:**
Edit `app/page.js`:

```jsx
<HeroCinematicVideo 
  headline="Your Custom Headline Here"
  subtitle="Your custom subtitle here."
  primaryCTA={{ text: 'Custom CTA', href: '/contact' }}
/>
```
